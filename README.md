# asset_management_system

Asset Management System (Flutter).

## Getting Started

- **Run (dev)**:

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=http://192.168.68.119:8000
```

- **Build (release)**:

```bash
flutter build apk --release --dart-define=API_BASE_URL=https://api.example.com
```
